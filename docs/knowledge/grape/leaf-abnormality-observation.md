# 葡萄叶片异常观察：先描述，再核实

看到葡萄叶片变黄、斑点、卷曲或失绿时，先把现象写清楚，暂不把它直接命名为某种病。记录新叶还是老叶先出现，叶缘还是叶脉之间变化，正面和背面是否一致，是否有虫体、虫卵、蛛网或可见附着物。再观察同株其他叶片及相邻植株，区分零散发生、沿行发生和整片发生。

将异常叶与同一地块外观正常的叶片分别拍照，保留植株位置和时间。回看近期天气、灌溉、施肥及其他作业记录，能够为进一步核查提供线索，但时间先后本身不证明因果。叶背的小型虫体及其活动痕迹也值得记录；如果无法辨认，应写“待识别”，而不是让自动识图结果变成确诊。复查关注新增位置、面积变化及新生组织状态。营养、根系、水分、病虫及环境因素可能表现相似，需要当地专业人员结合现场和必要检测判断。
