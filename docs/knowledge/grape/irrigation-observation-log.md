# 葡萄灌溉观察与记录：把供水和土壤变化连起来

判断灌溉情况，需要把降雨、供水记录、土壤变化与植株表现放在一起看。开始记录前，注明地块、土壤类型、灌溉分区和传感器位置；同一分区的低洼处与较高处可能并不相同。多深度墒情有助于观察不同土层对降雨或灌水的响应，但传感器读数只代表其附近土体，不能直接等同于整块园的水分状况。

一次灌溉应记录开始与结束时间、累计水量、流量和压力是否稳定，并巡查末端滴头、漏水点及积水。完成后比较各深度曲线与现场土壤情况，保留没有明显响应的测点，供核查安装接触、堵塞或分区供水问题。不要只凭表层湿润就判断根区供水充分，也不要根据单次百分比读数立刻追加灌溉。实际水量与时机需要结合土壤持水特性、根区、生育期和当地管理要求确定，本资料不提供通用启动阈值。
