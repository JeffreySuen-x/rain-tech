# 葡萄园巡田与拍照：让同一处变化可比较

巡田先确认地块、品种和当前生育阶段，再沿相对固定的路线观察园边、园中与曾出现问题的位置。记录看到的现象，也记录未见明显异常的区域，避免只留下最严重的一株。观察对象包括新梢、叶片、花果与地表积水等，并区分单株、连续数株或整行出现的情况。

拍照可以依次留下地块全景、整株位置和局部细节。叶片拍正反两面，保留清楚的叶脉、叶缘与斑点边界；用不遮挡症状的参照物表达大小。每组照片附日期、地块、行株位置、观察人、近期降雨及农事操作。复查时尽量使用相近位置和光线，并保留原图。照片能够支持对比和远程沟通，但颜色会受光照影响，单张图片不足以确认病因。发现快速扩展的异常时，应带着位置记录联系当地农技人员，由现场检查决定是否需要采样。
