# 葡萄园环境监测怎么读：先看时间、位置和趋势

查看气象与叶面湿度数据时，先核对采集时间、设备位置、单位和最近更新时间。空气温度、相对湿度、降雨、风速和叶面湿润反映不同现象；空气湿度高不必然表示叶片表面已经有水，叶面湿润读数也不能代替土壤墒情。看趋势时把降雨、叶面湿润持续情况和巡田观察放在同一时间线上，帮助安排重点复查。

设备突然出现长时间不变、跳变或中断，应先查供电、通信、传感器污染和维护记录。页面中的“在线”只能说明通信状态，不能说明葡萄生长安全。病害风险模型还依赖病原、生育期和地区适用性，不能把一个风险标签当作发病确诊。霜冻观察应关注园内不同位置与高度的温度差、风及地形；风机效果与逆温等条件有关，不能凭单个空气温度自动决定启动。本演示仅展示监测思路，不设置生产联动。
