# 葡萄园设备巡视：通信、测量与作业分别检查

设备巡视先核对设备编号、地块与安装位置，再检查外壳、支架、太阳能板和线缆是否损伤、遮挡或松脱。页面有新数据时，仍需核查雨量口、叶面传感器及虫情相机是否被灰尘、树叶或虫体遮挡。更换诱捕材料或清洁部件后记录时间，保留前后照片；不同诱芯服务的目标虫种不同，不能把所有捕获数混成同一种虫害压力。

对灌溉设备，同时查看阀门状态、流量、压力及末端出水。控制器显示开启不等于水已经均匀送达根区，异常应结合现场检查定位。水肥监测的电导率与酸碱度需要核查探头维护和校准记录，不能直接解释为植株吸收量。无人机影像可辅助寻找空间差异，异常区域仍要落地复查；演示页面不代表具备飞行、控制或自动诊断能力。维护应按厂家说明执行，带电、承压或旋转设备的处理交由具备相应能力的人员。
