# 葡萄农事记录与复盘：把做过的事变成证据

农事记录应能回答谁在什么时间、哪个地块、做了什么、为什么做以及后来看到什么。一次巡田、灌溉、修整或设备维护都可以成为记录；把计划与实际执行分别保存，避免事后把计划误写为已完成。记录关联照片、监测曲线和操作者备注，有助于下一次查找同一位置的变化。

复盘可以围绕一个具体问题展开，例如某分区叶片异常为何持续扩大。先排列天气、观察、操作和复查的时间顺序，标明缺失数据；再比较附近管理与条件相近的区域。发现操作之后情况改善，只能先作为线索，不能自动认定措施有效，因为天气与植株阶段也在变化。对尚未核实的解释写“待验证”，并明确下次复查的位置和要观察的现象。记录错误宜保留更正说明，便于追溯。本资料用于观察与管理记录，不代替当地农技指导，也不据此推荐药剂、剂量或采收间隔。
